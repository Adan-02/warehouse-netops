# 硬件采购清单

核对日期：2026-11-19。按现有方案采购：路由器负责分区和 WireGuard，现有电脑负责 Docker，先部署一个 ESP32 + DHT22 采集端。

## 必备物料

| 物品 | 最低数量 | 本项目要求与购买关键词 |
| --- | --- | --- |
| OpenWrt 无线路由器及匹配电源 | 1 套 | 至少 1 个独立 WAN、1 个 LAN；2.4 GHz 无线驱动支持至少两个 AP/SSID 并分别绑定网络；可运行受支持的 OpenWrt、firewall4、WireGuard、SSH/UCI。新购资源建议不低于 RAM 256 MB、Flash 128 MB，说明见下文。 |
| ESP32 开发板 | 1 块 | 搜索“ESP32 DevKit ESP32-WROOM-32E 4MB 已焊排针 USB转串口”。经典 ESP32-WROOM-32/32E、板载天线，能引出 GPIO4、3V3、GND。可买带 USB-C 的兼容开发板，按商品照片核对接口。 |
| DHT22 / AM2302 温湿度模块 | 1 个 | 优先三针、已焊排针、带数据脚上拉电阻的模块，支持 3.3 V 供电及逻辑。搜索“DHT22 AM2302 三针模块 3.3V”。 |
| 母对母杜邦线 | 1 排 | 2.54 mm、10–20 cm，至少 3 根；选已焊公排针的开发板和传感器可直接连接。 |
| USB 数据线 | 1 根 | 必须能传数据，接口匹配所买 ESP32；现有可用数据线可复用。用于烧录、串口和供电。 |
| RJ45 网线 | 2 根 | 成品 Cat5e 或 Cat6，1–2 m 即可；一根连接服务电脑到 LAN，一根连接模拟总部终端到 WAN。可多备 1 根。 |
| 服务电脑 | 复用 1 台 | 当前电脑已运行过项目 Docker 服务。采购规划可按 64 位系统、8 GB RAM、约 20 GB 可用磁盘起步；同时开虚拟机建议 16 GB RAM 和更多磁盘空间。这是本项目建议，不是软件厂商的通用最低配置。 |
| 模拟总部终端 | 借用 1 台优先 | 一台能运行 WireGuard、浏览器和测试工具的旧笔记本/实验室电脑即可；需独立接入 WAN。办公 Wi-Fi 测试可用现有手机或笔记本轮流完成。 |

ESP32 当前代码使用 `esp32dev` 板定义。ESP32-C3、S3、C6 和 ESP8266 需要额外适配，本清单优先选经典 ESP32。DHT11、DS18B20 不符合当前默认传感器型号。乐鑫官方 DevKitC 文档可用于核对模块、USB 转串口及引脚：[ESP32-DevKitC V4](https://documentation.espressif.com/api/resource/path/docs/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html)。

## 路由器怎么选

新购建议 RAM ≥ 256 MB、Flash ≥ 128 MB，是为安装、升级和排错预留空间的采购标准，并非 OpenWrt 能启动的绝对下限。OpenWrt 官方设备页明确不建议新购 8 MB Flash / 64 MB RAM 设备：[支持设备与选购提示](https://openwrt.org/supported_devices)。百兆有线和 2.4 GHz Wi-Fi 已能承载本实验，Wi-Fi 6、2.5G 不是功能硬性要求。

### 优先：GL.iNet GL-MT3000 / Beryl AX

官方规格为 512 MB RAM、256 MB NAND、一个 WAN 和一个 LAN，具备 2.4 GHz Wi-Fi；原配电源要求 5 V / 3 A。适合本项目的两条有线链路和无线分区，硬件余量充分。[官方规格](https://www.gl-inet.com/products/gl-mt3000/)

厂商提供不同固件分支；“基于 OpenWrt”不自动等于满足项目的 firewall4 和接口条件。到货后选与硬件匹配、仍受支持的 OpenWrt 固件，核对 `ubus`、`uci`、`fw4`、`wg`、无线多 AP 和实际端口，再适配脚本。厂商 OpenWrt 24 分支入口：[固件下载](https://dl.gl-inet.com/router/mt3000/openwrt24)。本项目尚未在该实机验收，不能承诺现有脚本原样应用。

### 低预算备选：小米 AX3000T 的 RD03（MediaTek）版本

仅在商品明显更划算、卖家能确认实机型号与安装条件时考虑。核对底部型号、芯片平台和原厂固件版本；能否进入所需安装流程也要确认。

不能只凭“AX3000T”商品标题下单。OpenWrt 官方设备页检索结果将 RD03v2 列为不同的 Qualcomm 硬件，并提示尚不支持；第三方移植不等于本项目已验证的官方支持路径。[官方设备页](https://openwrt.org/toh/xiaomi/ax3000t)

给路由器卖家的询问文本：

> 请确认实际发货的完整型号与硬件版本，并提供底部标签照片。我要用于 OpenWrt 实验，需要 SSH/UCI、firewall4、WireGuard，以及 2.4GHz 同时运行两个独立 SSID。请说明原厂固件版本、匹配的固件来源和恢复方法；如果是 AX3000T，需要确认是 MediaTek RD03，而非 RD03v2。

## 两种最低实验接法

优先用两台现有电脑：服务电脑接路由器 LAN，借来的总部电脑接 WAN；ESP32 接 IoT SSID，手机或笔记本接 Office SSID。一个 WAN、一个 LAN 足够，暂不需要交换机。

只有一台电脑也能做，但要用虚拟机和两块独立有线网卡分别连接 LAN 与 WAN，明确网卡的归属与隔离；普通共享 NAT 虚拟机不能直接替代这个拓扑。若原有一个 RJ45，可考虑补一个 USB 网卡，并为虚拟机预留内存。此方案联调更复杂，优先借第二台电脑。

Docker、数据库和看板继续运行在现有电脑上。无需为首版另买树莓派、x86 软路由主机、NAS、工业网关、云服务器、显示屏、继电器或烟雾传感器。

## 可直接照着下单的最小组合

- 路由器一套：优先 GL-MT3000，带匹配电源；低预算按上述条件核验 RD03 备选。
- 经典 ESP32-WROOM-32/32E 开发板一块，4 MB Flash、板载 USB 转串口、排针已焊。
- DHT22 / AM2302 三针模块一个，已焊针、3.3 V 可用、带上拉。
- 母对母杜邦线一排；匹配 ESP32 的 USB 数据线一根；Cat5e/Cat6 网线两根。
- 缺少有线网口的电脑补 USB 网卡；总部终端先借用。

此清单未采集电商实时到手价。型号与技术条件用于筛选，具体预算按购买平台报价核算；不要因为组合套餐便宜而换成其他 ESP32 系列或其他传感器型号。

到货后先拍型号、版本和接口，再做上电、串口、传感器读数和路由器备份；随后完成分区及 VPN 联调。实物验收状态仍以 `PROGRESS.md` 和 `evidence/` 的实测记录为准。
