# 个人练习记录模板

将本模板复制到项目根目录下的 `.local/learning/RECORD.md`，在本机填写。该目录已被 Git 忽略。项目版本中只保存空白模板，个人答案和自评留在本机。

不填写密码、令牌、许可证内容或私钥。只记录实际做过的操作和观察；未操作的内容写为预测。
